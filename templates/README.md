# Student Management System

## Project Description

Student Management System is a web-based application developed using Python Flask, HTML, CSS and MySQL.

This system helps to manage student records easily.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- MySQL
- MySQL Connector

## Features

- Add Student
- View Students
- Search Student
- Edit Student
- Delete Student
- Store student data in MySQL Database

## Student Information

The system stores:

- Student ID
- Student Name
- Email
- Phone Number
- Course
- Department
