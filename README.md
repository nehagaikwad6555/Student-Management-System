# Student Management System

## Project Description

Student Management System is a web-based application developed to manage student records easily and efficiently.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- MySQL

## Features

- Add Student
- View Students
- Search Student
- Edit Student
- Delete Student
- Store student records in MySQL database

## Database

Database Name: student_management

Table Name: students

## How to Run

1. Install Python
2. Install Flask
3. Install MySQL Connector
4. Run the Flask application using:

python app.py

5. Open the application in a web browser.

## Conclusion

The Student Management System provides a simple and efficient way to manage student information using a web application and MySQL database.
